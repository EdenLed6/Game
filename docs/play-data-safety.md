# Google Play Data Safety Draft

Use this as the starting point for the Google Play Console data safety form.

## Data Collected

No data is collected from the device or transmitted off the device in the current version.

## Data Shared

No data is shared with third parties.

## Local Data Stored

The app stores the following data locally only:

- Workbook draft answers
- Completed workbook exercises
- Revealed hints
- Completed lessons
- Challenge high score

## Security Practices

- No login in the current version.
- No cloud sync in the current version.
- No analytics or advertising SDK in the current version.
- No unnecessary Android permissions.
- Only the launcher activity is exported.
- Cleartext traffic is disabled.
- Android backup is disabled to keep workbook answers from being copied into cloud backups.
