# Privacy Policy Draft

This app is a local Japanese learning workbook for the Kimura beginner course.

## Data Collection

The app does not collect, transmit, sell, or share personal information.

## Local Learning Data

The app saves workbook answers, revealed hints, completed exercises, lesson progress, and challenge high scores locally on the user's device. This information is stored in private app storage and is not uploaded to a server.

## Permissions

The app does not request access to contacts, location, camera, microphone, SMS, calendar, external storage, or nearby devices.

## Network Access

The current version is designed to work offline and does not load arbitrary remote content.

## Account and Payments

The current version does not include login, account sync, subscriptions, in-app purchases, or payment processing.

## Data Deletion

Users can delete local learning data by clearing the app data from Android settings or uninstalling the app.
